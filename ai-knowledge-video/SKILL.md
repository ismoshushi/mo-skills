# AI 知识类视频剪辑

一套让 AI 按纪录片双轨法剪出"不一样"的知识视频的方法论。核心理念：**把画面只分成两类**——A-roll 讲人，B-roll 讲内容。AI 每个镜头的决策就简化成一件事：先选轨道，再套规则。

## 核心理念

- **A-roll / B-roll 双轨并行**（借鉴纪录片手法）：
  - A-roll = 讲人（IP 形象出镜）：承担观点输出（说结论）、讲述故事、衔接不同镜头（转场缓冲）。
  - B-roll = 讲内容（补充镜头）：承担观点论证（补充案例/数据）、内容的可视化表达。
  - 双轨交替是防枯燥的关键：画面只分两类，观众的注意力一直在"人"和"内容"之间切换。
- **编排表先行**：AI 直接剪容易跑偏。先把每个镜头在配音时间轴上的画面规划成一张"编排表"，检查通过后再动手剪。

## 四步工作流

### 第一步：文案 + 配音 + 对齐

- 文案先行（建议另起一套文案工作流，用 Claude / 豆包 / DeepSeek 写）。
- 配音要点：
  - 用 TTS（火山引擎豆包语音合成 2.0，新用户有免费额度；想用自己的声音可试开源声音克隆工具 voxCPM / Voicebox）把**整段文案一次性合成一个音频文件**——禁止分句单独合成，分句合成会让每句衔接不自然。
  - 哪个字发音不对，单独重新生成这一个字的音频再拼接进去。
  - 配音过程中不逐句询问用户。
- 对齐：用 whisper large-v3 做强制对齐，把配音转写为"时间轴 + 字幕"格式，例如 `[1249ms-3580ms] 这个问题其实很多朋友都有遇到`。
- 字幕分段规则：一段字幕 = 一小段配音，独立表达完整意思；每条控制在 **5–15 个字、最多 15 个字**；优先按标点符号断句，超长再按语义切分；**时间轴必须连续，不能重叠、不能有空缺**。

### 第二步：视觉编排表（最关键的一步）

- 基于字幕段和配音音频做分镜规划，输出编排表，包含：镜头号 / 时长 / 配音内容 / 画面类型（**只能是 A-roll 或 B-roll**）/ 画面描述（具体到能直接拿去做分镜，并说明与配音的配合关系）。
- 动手剪之前做**两项检查**：
  1. A-roll 和 B-roll 交替节奏是否自然——不能连续三四个镜头都是同一轨道。
  2. 逐镜头问"观众要理解的一句话是什么"，检查画面是否真正服务于这句话。

### 第三步：正式剪辑

**A-roll 两个关键：**

- **IP 形象一致性**：给一张 IP 角色参考图，让 AI 先分析（身型、几头身比例等）并生成规范化的角色三视图；再做一张场景图确定整体场景风格。正式生成时要求严格参照三视图（五官、体型、头身比例）+ 场景图（场景风格），背景简化/虚化以突出层次感；同时**固定机位构图和角色在画面的位置**。
- **表达视角多样性**：四种表达视角，按内容选用——
  1. 演示/教学（讲解演示）；
  2. 演绎（把故事演出来，如小剧场）；
  3. 旁观（第三视角，无人物）；
  4. 代入（第一视角 / POV）。
  
  避免每个镜头都是同一视角导致单调。

**B-roll 三种类型：**

1. 文字动画——关键词的语义可视化，重点突出句子结构；
2. 配图——概念可视化（讲流程用流程图、讲类比做类比图、软件教程直接用软件截图）；
3. 图表——数据可视化（折线图、柱状图）。

**B-roll 模板库**：常用结构每种提前做好 2–3 个动效模板（含 UI 规范），之后直接读取本地模板只替换文案，保持风格一致、快速出图。

### 第四步：样片和成片

- 先做 **1 分钟样片**（能完整看到 A-roll 和 B-roll 的节奏变化），检查：BGM 音量、字幕是否对版。
- BGM：用无版权音乐（爱给网），风格适配内容（知识干货类偏轻快快节奏，配合 A/B-roll 变化）；也可用音频生成模型定制。
- 音效：数量不宜多、音量不宜大。
- 封面图：从成片文案里提炼封面语，生成封面图。

## 工具清单（按需选用）

| 环节 | 工具 |
|---|---|
| Agent 执行 | Codex（自带生图模型）或 workbuddy（需自备生图模型 API） |
| 动效/镜头运动/时间轴渲染 | HyperFrames（Codex 插件市场搜索安装）；替代方案 Remotion（帧数控制，动效可控性更好、模板生态更成熟） |
| 配音 | 火山引擎豆包语音合成 2.0 / 开源声音克隆（voxCPM、Voicebox） |
| 强制对齐 | whisper large-v3 |
| 后期微调 | ChatCut（需要自己动手改时用） |

## 质量门禁

- 开工前：编排表两项检查（交替节奏 + "观众要理解的一句话"）必须通过。
- 样片阶段：BGM 音量、字幕对版、A/B-roll 节奏三项必须过。
- 红线（出现任何一条打回重做）：字幕时间轴重叠或空缺；IP 形象前后不一致；连续三四个同轨道镜头。

## 触发与边界

- 用户说"做个知识视频""帮我剪一条干货视频""把这篇文案做成视频"时启用。
- 只做方法与流程：文案内容质量由用户或文案工作流负责；本 skill 不承诺商单转化效果。
- 进阶：想给动效加"镜头配方"词汇库时，可再研究开源动效示例库的思路（HyperFrames 官方示例、Remotion 动效配方卡），按本 skill 的 B-roll 模板库方式沉淀为自己的模板。
