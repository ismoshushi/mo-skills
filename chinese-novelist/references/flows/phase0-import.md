# 已有大纲接入：把写了一半的小说接进来（针对 issue #12）

**场景**：用户已经有世界观文档、人物设定、大纲，甚至已经写好的章节，
想让 skill 接手继续写，而不是从零开始。

## 接入流程

### 1. 收料：让用户给现有材料

问用户要以下材料（有就给，没有就跳过）：

| 材料 | 用途 |
|---|---|
| 世界观/设定文档 | 生成 `00-设定字典.md` |
| 人物小传/人物卡 | 并入 `00-人物档案.md` |
| 大纲（细纲/章纲） | 生成 `02-写作计划.json` |
| 已写好的章节正文 | 直接归档为 `第XX章-xxx.md`，不重写 |
| 样章（认为写得最好的 1–2 章） | 提炼 `03-文风基准.md` |

材料可以是粘贴文本，也可以是文件路径。一次给不全没关系，先接已有的。

### 2. 设定文件生成（缺啥补啥）

- **有世界观文档** → 逐条拆成设定条目，写入 `00-设定字典.md`，
  冲突的设定标出问用户（不要自己脑补二选一）
- **有人物材料** → 整理进 `00-人物档案.md`（外貌/性格/目标/口头禅/关系网），
- **只有大纲、没有设定文档** → 从大纲和已写章节里反推设定，
  整理成初版设定字典，标"待确认"让用户过一遍

### 3. 大纲转换

把用户的大纲转成 `02-写作计划.json` 的分章结构：

- 大纲里已明确的章节 → 一一对应，`status` 标 `planned`
- 用户已写好的章节 → 按"第XX章-标题.md"归档，`status` 标 `completed`，
  **正文原样保留，一个字不改**
- 大纲没覆盖到的后续章节 → 按故事弧线补齐，标 `planned`，让用户确认

### 4. 文风基准提炼（重要）

从用户指定的样章（或已写章节中质量最高的 1–2 章）提炼：

- 句式节奏（长短句比例、对话密度）
- 叙事视角和语气
- 高频修辞手法和禁用清单（用户写崩过的句式）

写入 `03-文风基准.md`。后续所有新章节都对标它写，
解决"续写像换了个人"的问题（issue #30 的一半根源在这里）。

### 5. 术语表冷启动

从已有章节正文里扫描专有名词（人名/地名/功法/组织），
写入 `04-术语表.md`，首现章节标"第X章已出场"。
新章节再出现这些词时不再解释，直接用。

## 接入完成检查单

- [ ] 设定文件与用户材料一致，无脑补
- [ ] 已写章节原样归档，未被改写
- [ ] 写作计划 JSON 里 completed/planned 状态与实际相符
- [ ] 文风基准来自用户的样章，不是通用模板
- [ ] 告诉用户：从第 X 章开始续写，沿用你的文风

完成后进入第三阶段（写作），从"下一章"开始。
