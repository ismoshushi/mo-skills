# 人生复盘 · Life Review

带用户做一次彻底的人生复盘：AI 当"绝对中立的镜子"，用 45–60 分钟语音深访，
翻出人生各阶段的高光低谷、关键选择的驱动力、反复出现的主题，
最后输出一份六部分个人分析报告——照见那套一直在跑的"隐形代码"。

灵感来源：[@noahduck283 的人生复盘方法](https://x.com/noahduck283/status/2110719834581598276)
（方法框架借鉴，提示词与流程均为原创整理）

## 怎么用

跟 AI 说"做一次人生复盘"，然后：

1. **准备**：找个安静的晚上，戴耳机，用语音输入，留 1 小时
2. **访谈**：AI 一次只问一个问题，带你回顾人生五个维度（高光低谷/感受/选择的驱动力/重复主题/对未来的渴望与恐惧）
3. **追问**：聊到卡点时，深挖你一直在回避的核心问题和自我设限
4. **报告**：六部分个人分析报告——核心人生模式、优势与盲点、人际情感模式、
   深层驱动力与恐惧、三条战略建议、推荐的理论/书/历史人物

## 效果最好的方式

- 用语音说出来，不要打字（打字会让防御机制上线）
- 感到不想回答、烦躁、"这有什么好说的"——恰恰是核心问题接近的信号
- 访谈阶段 AI 只记录不给建议，报告最后才出
