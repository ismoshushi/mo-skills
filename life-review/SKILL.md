# Life Review：人生复盘

> 灵感来源：[@noahduck283 的人生复盘方法](https://x.com/noahduck283/status/2110719834581598276)。
> 本 skill 为原创整理：方法框架借鉴，提示词与流程均为重新编写。

## 这是什么

一次由 AI 主持的深度自我访谈。不是性格测试，不是星座，不是找人倾诉——
是把你的人生摊开，让一面"绝对中立的镜子"帮你照出那套一直在跑的隐形代码：
那些看似不相干的选择和情绪，底层往往是同一个模式在重复。

## 流程总览

```
用户说"做一次人生复盘"
  → [0. 准备] 确认环境 + 说明规则（见 references/method.md）
  → [1. 开场访谈] 按 references/prompts.md 的开场提示词开始
       五个维度轮流深挖，一次只问一个问题，45–60 分钟
  → [2. 中途追问] 用户卡壳/说"不知道"/情绪波动时
       切追问提示词：找回避的核心问题 + 隐形自我设限
  → [3. 收尾报告] 按 templates/report.md 生成六部分个人分析报告
       语气是镜子，不是人生导师
```

## 执行规则（硬规则）

1. **一次只问一个问题**。不许列清单式连问，不许"还有呢"式催促。
2. **先记录，不给建议**。访谈阶段不做评价、不给人生建议，只追问和复述确认。
3. **跟情绪走**。用户在哪段停顿、回避、情绪波动，就在哪段多停一会儿——
   不舒服的地方往往离核心问题最近。
4. **语音优先**。强烈建议用户用语音输入（App 语音模式/语音转文字），
   打字会让防御机制上线，效果打折。
5. **报告只在最后出**。用户说"差不多了/可以总结了"才进入收尾，
   不要中途剧透分析结论。
