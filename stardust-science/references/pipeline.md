# 分镜 pipeline 说明

## 输入 → 输出

```
科学概念（一句话）
  → 联网调研（定义 / 关键数据 / 视觉钩子）
  → 分镜 JSON（发用户确认）
  → build.py → index.html（预览）
  → render.mjs → MP4（成片）
```

## 写作铁律

1. **数字先行**：每个分镜至少 1 个硬核数字（质量、距离、温度、年份），数字必须来自第 1 步调研。
2. **一镜一句话**：narration 就是字幕，每镜只讲一件事，口语化，短句。
3. **视觉钩子前置**：最震撼的画面（黑洞吸积盘、粒子大字）放在第 1–2 镜。
4. **时长**：单镜 4–10 秒，全片建议 60–150 秒；口播按每分钟约 220 个汉字估算时长。
5. **不编造**：不确定的数据写"约"或删掉；不要出现"科学家认为"这种无来源表述。

## 风格参数（模板内置）

- 深空黑底 + 三层视差星空 + 慢速星云漂移
- 金白星芒粒子大字（开场/收尾）
- 语义配色：高温/能量用金橙（255,200,120），低温/远端用冷蓝（140,180,255）
- 大字幕：54px，底部居中，手机可读
- 胶片颗粒 + 暗角，纪录片质感
