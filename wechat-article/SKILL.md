# WeChat Article：公众号文章一条龙

一个 skill 干完公众号发文的全部脏活：**写稿 → 排版 → 发布**。

## 流程总览

```
用户给主题/素材
  → [1. 选题定调] 角度 + 目标读者 + 一句话卖点
  → [2. 列大纲] 标题候选3个 + 开头钩子 + 分节结构 → 用户确认（只确认这一次）
  → [3. 写正文] 按 references/writing.md 的技法写 Markdown 初稿
  → [4. 排版] scripts/md2gzh.py 转成公众号 HTML（手机端优化）
  → [5. 配图] 封面图要求 + 文中配图位建议
  → [6. 发布] 建草稿：API 自动（scripts/gzh_draft.py）或手动复制（二选一）
```

> 原则：大纲确认后不再打扰用户，一口气干到草稿箱。标题和开头是唯二值得返工的地方。

## 各阶段说明

### 1. 选题定调

先问清三件事（用户没给就按默认补）：
- **给谁看**：默认"关注 AI/搞钱的中文读者"
- **想达到什么**：涨粉 / 转化 / 立人设，默认"涨粉"
- **一句话卖点**：这篇文章凭什么被点开，压缩成 20 字以内

### 2. 列大纲（唯一需要用户确认的环节）

输出：3 个标题候选（风格各不相同）+ 开头钩子（一句话）+ 分节小标题。
用户选定标题后进入写作，不再回头。

### 3. 写正文

读 `references/writing.md`，按里面的技法写。硬要求：
- 全文 Markdown，口语化短句，一段不超过 3 行（手机屏）
- 每 300 字左右一个小标题或金句，制造"滑下去"的节奏
- 结尾必须有互动钩子（提问 / 投票 / 引导关注）

### 4. 排版

跑 `scripts/md2gzh.py 稿件.md`，输出公众号兼容 HTML（全部内联样式，手机端字号/行距已调好）。
排版规范见 `references/typesetting.md`。如需换主题色，改脚本顶部的 `THEME` 配置。

### 5. 配图

- **封面图**：900×500，标题大字 + 高对比底图，不要纯文字白底
- **文中图**：每 800–1000 字一张，位置在小节开头；给用户列出配图位清单让他找图（或用 AI 生图）
- 图片先传公众号素材库拿 media_id，再进正文

### 6. 发布（二选一）

- **API 路线**（推荐）：配好 `appid`/`appsecret`，跑 `scripts/gzh_draft.py`，
  自动传图 → 建草稿 → 用户去公众号后台点"群发"就行。详见 `references/publishing.md`
- **手动路线**：把第 4 步的 HTML 复制进公众号后台编辑器，传图、预览、存草稿

## 文件说明

| 文件 | 干嘛的 |
|---|---|
| `references/writing.md` | 公众号写作技法：标题公式、黄金开头、结构、金句 |
| `references/typesetting.md` | 排版规范：字号行距、标题/引用/代码样式、主题配置 |
| `references/publishing.md` | 发布指南：API 配置、草稿流程、群发注意事项 |
| `scripts/md2gzh.py` | Markdown → 公众号 HTML（零依赖，本地可测） |
| `scripts/gzh_draft.py` | 公众号 API：获取 token、上传图片、创建草稿 |
| `examples/sample.md` | 示例输入稿 |
