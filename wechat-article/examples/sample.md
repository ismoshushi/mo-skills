# 我花 3 天测了 8 个公众号写作 skill，第 1 名出乎意料

凌晨 1 点，我第 5 次删掉了写好的开头。不是写不出来，是市面上的公众号 skill 太多了，挑花了眼。

## 先说结论

**最好用的不是最火的**，而是最适合你工作流的。下面这 3 个，是我真实用过的：

- 全流程型：选题到发布一条龙，适合新手
- 排版型：只干排版，但干到极致
- 写作型：专治"写不出来"

> 提醒一句：skill 只是流程，文笔上限永远看模型。别指望装个 skill 就 10 万+。

## 排版才是第一生产力

很多人不知道，公众号**首图和排版**决定了 50% 的打开率。记住三件事：

1. 字号 15px，行高 1.75，这是手机阅读的黄金比例
2. 一段不超过 3 行，多分段
3. 每 800 字配一张图

---

举个例子，下面这段代码是转换器的核心：

```
def inline(md):
    return re.sub(r"\*\*(.+?)\*\*", r"<b>\1</b>", md)
```

写完别忘了手机预览一遍，错位、超宽图、代码块不能横滑，是最常见的 3 个坑。
