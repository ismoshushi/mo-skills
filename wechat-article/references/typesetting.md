# 公众号排版规范

> 公众号编辑器会过滤 `<style>` 标签和外部 CSS，**所有样式必须写成内联 style**。
> `scripts/md2gzh.py` 已按本规范实现，改主题只改脚本顶部的 `THEME`。

## 基础规范（移动端优先）

| 项 | 值 | 说明 |
|---|---|---|
| 正文字号 | 15px | 太小费眼，太大显low |
| 行高 | 1.75 | 呼吸感就靠它 |
| 段间距 | 16px | 段与段空一行 |
| 两端对齐 | text-align: justify | 右边缘齐，看着贵 |
| 首行缩进 | 无 | 公众号不缩进，靠段间距分隔 |
| 正文颜色 | #3f3f3f | 纯黑 #000 太生硬 |
| 链接颜色 | #576b95 | 微信官方链接蓝 |

## 组件样式

- **一级小标题**：16px 加粗，左侧 4px 主题色竖条（border-left），上下各空 12px
- **二级小标题**：15px 加粗，主题色文字
- **引用**：浅灰底（#f7f7f7）+ 左侧主题色边框，14px
- **分割线**：用"＊ ＊ ＊"居中，比 `<hr>` 好看
- **加粗**：主题色加粗，专治"划重点"
- **代码块**：等宽字体，浅灰底，横向可滚动（别指望换行）
- **图片**：width:100%，居中，下方 12px 灰色小字图注
- **二维码/引导关注**：放文末独立区块，浅底圆角，别跟正文挤在一起

## 主题色建议

- 科技/AI：#1a73e8（蓝）
- 搞钱/干货：#e8590c（橙）
- 情感/生活：#d6336c（粉）
- 默认：#07c160（微信绿），最保险

## 排版禁忌

1. 一屏超过 3 种颜色 —— 花
2. 全文居中 —— 只有标题和分割线可以居中
3. 字号忽大忽小 —— 层级靠"字重+颜色+间距"区分，不靠字号
4. 大段文字不配图 —— 手机上超过两屏纯文字，跳出率翻倍
5. 用系统表情混排版 —— 不同手机渲染不一样，会错位

## Markdown 转换对照

| Markdown | 转换后 |
|---|---|
| `#` 一级标题 | 文章标题（只允许 1 个，放开头） |
| `##` 二级标题 | 一级小标题（竖条样式） |
| `###` 三级标题 | 二级小标题（主题色） |
| `> 引用` | 引用块 |
| `**加粗**` | 主题色加粗 |
| `![图注](url)` | 居中图片 + 图注 |
| `---` | ＊ ＊ ＊ 分隔 |
| `` `code` `` / 代码块 | 行内码 / 代码块 |
| `- 列表` | 主题色圆点列表 |
