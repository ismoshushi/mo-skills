# 微信贴图号 · WeChat Sticker

公众号"贴图号"一条龙：选 AI 热点 → 写 ≤250 字口语化文案 →
生成 4 张 3:4 竖屏图 → 走公众号**官方 API**存图文草稿（多图少文近似贴图形态）。

灵感来源：[@7998l201 的 Muse 自动运营贴图号实操](https://x.com/7998l201/status/2111258888146468968)
（方法框架借鉴，文档与脚本均为原创整理；存草稿走官方 `draft/add` 接口）

## 工作流

```
你说"来一条贴图"（可指定话题，也可让我推荐）
  → 定话题（AI 热点，选不到可靠的就停更，不编造）
  → 写文案（≤250 字：谁发布了什么 → 为什么值得看 → 提醒 → 来源）
  → 生成 4 张图（3:4 竖屏：主图/参数对比/核心能力/落地场景，风格二选一）
  → 存草稿（scripts/sticker_draft.py，官方 API）
  → 你去草稿箱核对，手机端预览后手动发表
```

## 硬规则

- 只建草稿，不群发（脚本里就没有群发功能）
- 文案超 250 字脚本直接报错
- 一条一个风格，不混搭；每条单独预览，不盲发

## 快速上手

```bash
export GZH_APPID="wx..." GZH_APPSECRET="..."

python3 scripts/sticker_draft.py \
  --title "一句话标题" \
  --copy 文案.txt \
  --images 主图.png 对比.png 能力.png 场景.png
```
