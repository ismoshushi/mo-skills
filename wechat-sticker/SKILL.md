# WeChat Sticker：微信贴图号一条龙

> 灵感来源：[@7998l201 的 Muse 自动运营贴图号实操](https://x.com/7998l201/status/2111258888146468968)。
> 本 skill 为原创整理：方法框架借鉴，文档与脚本均为重新编写；
> 存草稿走公众号官方 API（`draft/add`），不用未公开接口。

## 一条贴图 = 什么

- 1 篇图文草稿：标题（短）+ ≤250 字中文文案 + 4 张 3:4 竖屏图
- 形态上是"多图少文"的图文，用来近似贴图号的刷屏体感
- 全程只到草稿为止，发表永远是人手动点的

## 流程总览

```
用户说"来一条贴图"（可指定话题，也可让我推荐）
  → [1. 选题] 按 references/topic.md 定话题 → 用户确认
  → [2. 文案] 按 references/copy.md 写≤250字文案 → 用户确认
  → [3. 图片] 按 references/image.md 生成 4 张 3:4 竖屏图
  → [4. 存草稿] scripts/sticker_draft.py --title --copy --images
       → 返回 media_id，去草稿箱核对
  → [5. 发表] 用户手机端（公众号助手）逐条预览 → 手动发表
```

## 硬规则

1. **只建草稿，不群发**。脚本里没有群发功能，发表必须人去后台点。
2. **不编造**。选不到可靠热点就停下，告诉用户今天没合适的；不编价格、链接、数据。
3. **文案≤250字**（含标点空格），超了脚本会直接报错退出。
4. **一条一个风格**。4 张图风格统一，不混搭。
5. **每条单独预览**。不攒一批盲发。

## 文件说明

| 文件 | 干嘛的 |
|---|---|
| `references/topic.md` | 热点选题规范：从哪选、什么算可靠、什么时候停下 |
| `references/copy.md` | 文案规范：≤250字、四段式结构、口语化 |
| `references/image.md` | 图片规范：4 张分工、3:4 竖屏、两种风格 |
| `references/publishing.md` | 存草稿、核查、手机端发表清单 |
| `scripts/sticker_draft.py` | 官方 API：传图 → 建图文草稿（零依赖） |
| `examples/sample.md` | 示例：一条贴图的文案 + 配图说明 |
