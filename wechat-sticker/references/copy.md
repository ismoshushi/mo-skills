# 文案规范

## 硬指标

- **≤250 字**，含标点和空格。超了脚本报错，自己先数好。
- 中文口语化，像朋友转述，不端着。
- 不编价格、链接、数据；不确定的写"具体见官方"。

## 四段式结构

1. **谁发布了什么**（一句话，信息本身）
2. **为什么值得看**（对读者有什么用，解决什么问题）
3. **提醒/注意**（限制、价格、适用人群，有一说一）
4. **来源提示**（"消息来自 XX 官方博客"放末尾）

## 语气

- 短句为主，一句话一个意思
- 可以有观点，但观点和事实分开写
- 不标题党：文案里承诺的，图里要有

## 自查

- [ ] ≤250 字
- [ ] 四段都在，没有缺"来源提示"
- [ ] 没有编造的数字和链接
- [ ] 读一遍像人话
